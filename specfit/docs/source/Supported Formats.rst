Supported Formats
=================
Listed are the currently supported formats. 

  - .spx
  - .MCA
  - .BCF
  - .hdf5
  - .h5
  - .MSA
  - .spe
  
.. |ico1| image:: _static/icons/warning.png
   :height: 3ex

.. warning:: |ico1| Most file formats follow specific rules. If your file has different keys or structure **SpecFit** may not recognise it. Please contact! |ico1|

For *.BCF*, *.spx* and *.msa* example measurements are available.

Depreceated and Unmaintained Formats
------------------------------------
Depreceated and legacy support is available for the following formats
 
  - .txt - converted from spx via *Bruker*s *Esprit*
  - .dat - converted from spx via *Bruker*s *Esprit*
  - .csv - converted from spx via *Bruker*s *Esprit*
